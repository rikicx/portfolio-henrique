## Duas licenças, dois escopos diferentes

Um Design System publicado tipicamente precisa de duas decisões de licença separadas, porque cobrem coisas diferentes:

- **Licença de código** — se algum código (tokens exportados, snippets, configuração) for distribuído junto do arquivo Figma, ele precisa de uma licença de software.
- **Licença de assets/design** — o arquivo Figma em si (Components, Variables, Styles, composições) precisa de uma licença de design/conteúdo, que trata de uso, adaptação e redistribuição do material visual.

Essas duas licenças podem ser iguais ou diferentes — é uma decisão a ser tomada, não uma consequência automática.

## Opções em consideração

Nenhuma das opções abaixo foi escolhida. Estão listadas apenas para decisão:

- **MIT** — permissiva, permite uso comercial e modificação, exige apenas atribuição.
- **Apache 2.0** — permissiva como a MIT, com termos explícitos adicionais sobre patentes.
- **CC BY 4.0** — licença de conteúdo/design, permite qualquer uso (incluindo comercial) desde que com atribuição.
- **CC BY-NC 4.0** — como a CC BY, mas proíbe uso comercial sem autorização adicional.
