# Community Listing — Kihon

## Descrição curta

Kihon — um Design System starter para portfólios e sites editoriais, com Foundations, Components, Patterns e orientações para Light & Dark, Desktop, Tablet e Mobile.

## Descrição completa

**O que é:** Kihon (基本, "fundamentos" em japonês) é um Design System starter — não um UI kit pronto, mas um ponto de partida sólido para construir um portfólio ou site editorial do zero.

**Para quem é:** designers que querem pular a etapa de definir tokens, tipografia e componentes básicos, e ir direto para adaptar marca e conteúdo.

**O que está incluído:** Foundations (cor, tipografia, spacing, grid, radius, elevation, iconografia, motion, temas claro/escuro), 11 Components reais — Button, Text Link, HyperLink, Project Card, Stat Card, Language Switcher, Theme Toggle, Field, Textarea, Footer e Quote — Patterns de escrita, acessibilidade e interação (incluindo o Pointer, cursor customizado), e orientação de composição de página em Templates.

**Como começar:** duplique o arquivo, leia "00 — Start Here", troque a paleta de cor e a tipografia em Foundations — os componentes consomem essas Variables automaticamente.

**O que pode ser adaptado:** marca, cor, tipografia e todo conteúdo de exemplo. A lógica de tokens e a estrutura de páginas devem ser preservadas.

**Limitações conhecidas:** Mobile Menu ainda não existe como componente, e a Nav Bar atual não possui composição para telas estreitas. Alguns Labels usam a fonte Inter Tight — instale-a para editar esses campos.

## Limitações conhecidas (detalhado)

- **Mobile Menu** não existe como componente — a Nav Bar não possui composição própria para telas estreitas.
- **Inter Tight** é necessária para editar os Labels de Button, Text Link, Nav Item, HyperLink e Stat Card. Sem a fonte instalada, esses campos não podem ser editados pelo Properties panel.
