# Release Notes — Kihon v1.0

## Foundations

Cor (primitivos + semânticos), tipografia, spacing, grid, radius, elevation, iconografia e motion — todos documentados com Variables reais.

## Light/Dark

Temas claro e escuro completos, implementados via Figma Variables. Cada componente responde automaticamente à troca de modo.

## 11 Components

Button, Text Link, HyperLink, Project Card, Stat Card, Language Switcher, Theme Toggle, Field, Textarea, Footer e Quote — todos como component sets reais, prontos para instanciar pelo Assets panel.

## Patterns

Writing Patterns (convenções de escrita para títulos, labels, métricas e mensagens de formulário), acessibilidade, comportamento responsivo, Do/Don't e comportamento de componentes.

## Templates

Navigation e Footer como composições de referência, mostrando como os componentes se combinam em uma página real.

## Accessibility

Guidance de foco, contraste, validação de formulário e navegação por teclado documentada e aplicada nos componentes.

## Responsive guidance

Princípio de recomposição — cada padrão é adaptado para a tela, não apenas encolhido — documentado com exemplos de Desktop, Tablet e Mobile.

## Documentation

Orientação de uso por proximidade: cada página do arquivo ensina o que ela mesma contém, sem manual central separado.

## Known limitations

- Mobile Menu ainda não existe como componente; a Nav Bar não possui composição para telas estreitas.
- Inter Tight é necessária para editar alguns Labels.
- HyperLink ainda usa o default "See full profile ↗", específico demais para o caso genérico.
